The mini project demostrate:- class, constructors, methods, super, inheritance in java 
Then demonstrate how the child can use methods from the parent class 

It contains a parent class `Animal` and a child class `Dog`.
The `Dog` class inherits properties and methods from the `Animal` class.

 Functionality

Create an `Animal` object with a name.
Create a `Dog` object that extends the `Animal` class.
Demonstrate how the child class can use methods from the parent class.
